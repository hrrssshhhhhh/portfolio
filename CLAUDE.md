## Architecture

Fresh `create-next-app` scaffold for a personal portfolio, App Router only (`app/`, no `src/`).

- `app/layout.tsx` — root layout; loads Geist / Geist Mono via `next/font/google` as CSS vars. Uses the global `LayoutProps<"/">` type (typed routes, generated by Next) rather than hand-written prop types.
- `app/page.tsx` — home route (still template content).
- `app/globals.css` — Tailwind v4 (CSS-first: `@import "tailwindcss"` + `@theme inline`, no `tailwind.config.js`). Colors defined as `:root` vars with dark mode via `prefers-color-scheme`, exposed as `bg-background` / `text-foreground` utilities. Geist is mapped to `font-sans` / `font-mono`, but `body` still sets `font-family: Arial` — apply `font-sans` (or change the rule) for Geist to actually render.
- `next.config.ts` — notable flags:
  - `cacheComponents: true` — Cache Components mode; dynamic data access needs `<Suspense>` boundaries or `"use cache"`. Read the docs before adding data fetching.
  - `partialPrefetching: true`, `experimental.agentFeedback: true`.
  - Tailwind runs through a Turbopack CSS loader rule (`@tailwindcss/turbopack`), not PostCSS — there is no `postcss.config`.
- Path alias `@/*` → repo root.
